## 四问题修复轮（rgba 统一 / +/- 无效 / 颜色无效 / 分类改弹框）

- **根因**：编辑器直接就地改 `props.style` 嵌套属性（`v-model="style.xxx"`），对 props 对象的间接修改不可靠 → 边框尺寸 +/- 与取色都不生效。**修复**：改为「本地草稿 + 确认时显式写回」架构（`draft` reactive + `watch` 初始化 + 应用时 emit）。
- **rgba 统一**：`symbolization.ts` 新增 `toRgbaString()`（hex/rgb/rgba/hsl/hsla → rgba 字符串），编辑器回显与预览统一 rgba 格式。
- **分类设置改弹框**：分类列表行改为「sm 预览 + 值 + 设置按钮」，点击弹「符号设置 - {值}」子弹框（复用 `GisSingleSymbolEditor`），不再行内展开；列表预览随弹框确认实时更新。
- 浏览器实测：+/− 生效（2.0→2.5）、取色输入 rgba(0,0,255,1) 后预览/文本/重开回显一致、线型 dash 生效（stroke-dasharray 6 4）、分类弹框设置后应用成功且回显 4 分类 rgba 颜色、`符号化`标签出现，全程 0 JS 错误。
